# **🐳 Docker Command 

    ==========================================================================================
    COMMAND                                      | DESCRIPTION
    ==========================================================================================

    BASIC
    ------------------------------------------------------------------------------------------
    docker --version                              | Show Docker client version.
    docker version                                 | Show detailed client + server versions.
    docker info                                    | Display system-wide information.
    docker login                                   | Login to Docker registry.
    docker logout                                  | Logout from Docker registry.
    docker help                                    | Show help for commands.

    IMAGES
    ------------------------------------------------------------------------------------------
    docker search <image>                          | Search Docker Hub for an image.
    docker pull <image>                            | Pull image from registry.
    docker images                                  | List all local images.
    docker build -t <name>:<tag> .                 | Build image from Dockerfile.
    docker tag <src> <target>                      | Tag image with a new name.
    docker rmi <image>                             | Remove image.
    docker image prune                             | Remove unused images.
    docker image prune -a                          | Remove all unused images.
    docker inspect <image>                         | Inspect low-level image info.
    docker save -o file.tar <image>                | Save image to tar archive.
    docker load -i file.tar                        | Load image from tar archive.

    CONTAINERS (LIFECYCLE)
    ------------------------------------------------------------------------------------------
    docker run <image>                             | Create and start a new container.
    docker run -d <image>                          | Run container in detached mode.
    docker run -it <image>                         | Run interactively with terminal.
    docker run -p HOST:CONT <image>                | Map container port to host port.
    docker run --name <name> <image>               | Assign name to container.
    docker ps                                      | List running containers.
    docker ps -a                                   | List all containers.
    docker start <container>                       | Start existing container.
    docker stop <container>                        | Stop running container.
    docker restart <container>                     | Restart container.
    docker kill <container>                        | Force stop container.
    docker rm <container>                          | Remove container.
    docker container prune                          | Remove all stopped containers.

    CONTAINERS (OPERATIONS)
    ------------------------------------------------------------------------------------------
    docker exec -it <container> bash               | Execute bash inside container.
    docker exec -it <container> sh                 | Execute sh shell inside container.
    docker logs <container>                        | View container logs.
    docker logs -f <container>                     | Stream logs (follow).
    docker cp <container>:/path /host/path         | Copy from container to host.
    docker cp /host/path <container>:/path         | Copy from host to container.
    docker top <container>                         | Show processes inside container.
    docker stats                                   | Resource usage of containers.
    docker inspect <container>                     | Detailed container metadata.

    VOLUMES
    ------------------------------------------------------------------------------------------
    docker volume ls                               | List all volumes.
    docker volume create <name>                    | Create volume.
    docker volume rm <name>                        | Remove volume.
    docker volume prune                            | Remove unused volumes.
    docker run -v vol:/path <image>                | Mount named volume.
    docker run -v /host:/container <image>         | Bind mount host directory.

    NETWORKS
    ------------------------------------------------------------------------------------------
    docker network ls                              | List networks.
    docker network create <name>                   | Create new network.
    docker network rm <name>                       | Remove network.
    docker network inspect <name>                  | Show network details.
    docker network connect <net> <container>       | Attach container to network.
    docker network disconnect <net> <container>    | Detach container.
    docker run --network <name> <image>            | Run container on a network.

    REGISTRY
    ------------------------------------------------------------------------------------------
    docker login <registry>                        | Login to private registry.
    docker pull <registry>/<image>                 | Pull image from registry.
    docker push <registry>/<image>                 | Push image to registry.

    DOCKER COMPOSE (v2)
    ------------------------------------------------------------------------------------------
    docker compose up                               | Start all services.
    docker compose up -d                            | Start in detached mode.
    docker compose down                             | Stop and remove all services.
    docker compose down -v                          | Remove volumes too.
    docker compose build                            | Build services.
    docker compose restart                          | Restart services.
    docker compose ps                               | List services.
    docker compose logs                             | View logs.
    docker compose logs -f                          | Follow logs.
    docker compose exec <svc> sh                   | Exec into running service container.

    SYSTEM CLEANUP
    ------------------------------------------------------------------------------------------
    docker system df                                | Show disk usage.
    docker system prune                             | Remove unused data.
    docker system prune -a                          | Remove unused images + containers.
    docker system prune -a --volumes                | Aggressive clean including volumes.

    ==========================================================================================

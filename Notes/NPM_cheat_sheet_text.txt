## 🧭 Semver Ranges (Reference)

| Syntax       | Meaning                                 | Example        | Notes                         |
| ------------ | --------------------------------------- | -------------- | ----------------------------- |
| ^            | Compatible with next non-breaking major | ^1.2.3         | Allows 1.x updates, not 2.0.0 |
| \~           | Patch-level updates                     | \~1.2.3        | Allows 1.2.x                  |
| \*           | Any version                             | \*             | Avoid in production           |
| >=, <=, >, < | Comparators                             | >=2.1.0 <3.0.0 | Combine for ranges            |
| x or .x      | Wildcards                               | 1.x, 1.2.x     | —                             |
| -            | Hyphen range                            | 1.2.3 - 1.3.4  | Inclusive                     |

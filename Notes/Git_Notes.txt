🟢## git cherry-pick 

    +----------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Category                   | Command                                       | Description / Example                                       |
    +----------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | What is git cherry-pick    | git cherry-pick                               | Applies a specific commit from another branch to current     |
    |                            |                                               | branch (copies the commit)                                  |
    +----------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Basic usage                | git cherry-pick <commit-hash>                 | Applies the given commit to the current branch               |
    +----------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Use case (bug fix)         | git cherry-pick abc123                        | Picks a bug-fix commit from another branch                   |
    |                            |                                               | without merging the entire branch                            |
    +----------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Cherry-pick multiple       | git cherry-pick abc123 def456                | Applies multiple commits in sequence                         |
    | commits                    |                                               |                                                             |
    +----------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Cherry-pick a range        | git cherry-pick abc123..def456               | Applies all commits between abc123 and def456                |
    |                            |                                               | (excluding abc123)                                           |
    +----------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Pick single commit from    | git cherry-pick feature-login~2              | Picks a specific commit relative to HEAD                     |
    | branch history             |                                               |                                                             |
    +----------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Cherry-pick with conflicts | git cherry-pick abc123                        | Git pauses if conflicts occur                                |
    |                            |                                               | Resolve conflicts, then continue                             |
    +----------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Continue after conflict    | git cherry-pick --continue                   | Continues cherry-pick after resolving conflicts              |
    +----------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Abort cherry-pick          | git cherry-pick --abort                      | Cancels cherry-pick and restores branch state                |
    +----------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Skip commit                | git cherry-pick --skip                       | Skips the current cherry-pick during conflict resolution     |
    +----------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | No commit option           | git cherry-pick -n abc123                    | Applies changes but does NOT create a commit                 |
    |                            | (--no-commit)                                 | Allows manual edit before committing                         |
    +----------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Record original commit     | git cherry-pick -x abc123                    | Adds reference to original commit hash in message            |
    +----------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Cherry-pick vs merge       | cherry-pick                                  | Brings specific commits only                                 |
    |                            | merge                                        | Brings entire branch history                                 |
    +----------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Cherry-pick vs rebase      | cherry-pick                                  | Copies commits to target branch                              |
    |                            | rebase                                       | Rewrites commit history                                      |
    +----------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | When to use                | Bug fixes                                    | Apply hotfix from one branch to another                      |
    |                            | Selected features                            | Pick only required commits                                   |
    |                            | Release management                           | Move important commits to release branch                     |
    +----------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | When NOT to use            | Many dependent commits                       | Prefer merge or rebase                                       |
    |                            | Shared commit history                        | Cherry-pick may cause duplicate commits                      |
    +----------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Common workflow            | git checkout main                            | Switch to target branch                                      |
    |                            | git cherry-pick abc123                       | Apply commit from another branch                             |
    +----------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Key takeaway               | git cherry-pick                              | Powerful for selective commit transfer                       |
    |                            |                                               | Use carefully to avoid duplicate history                     |

🟢## Undo/revert/discard / UnDo Commit  changes

following list of command used for Undo/revert/discard /UnDo Commit changes

   reset                   Reset current HEAD to the specified state (undo commit  , change commit history)
   revert                  Revert some existing commits (undo commit , Move Head Specific Commit Location / commitId , not change commit history)
   restore                 Restore working tree files  (discard changes)

🟢## GIT revert # git revert use for undo commit

The git revert command undoes a previous commit by creating a new commit that reverses the changes.

git revert <commitid> 
git revert HEAD - Revert the latest commit
git revert <commit> - Revert a specific commit
git revert HEAD~2 - Revert a commit further back in history
git revert --no-edit - Skip commit message editor
git log --oneline - Show commit history

🟢## git switch

    +----------------------+-------------------------------------------+-------------------------------------------------------------+
    | Topic                | Command / Concept                          | Explanation / Example                                       |
    +----------------------+-------------------------------------------+-------------------------------------------------------------+
    | What is git switch   | git switch                                | Command introduced in Git 2.23 to switch branches only       |
    |                      |                                           | Simpler and safer alternative to git checkout                |
    +----------------------+-------------------------------------------+-------------------------------------------------------------+
    | Purpose              | Branch operations only                    | Used ONLY for switching or creating branches                 |
    |                      |                                           | Does NOT restore or discard files                            |
    +----------------------+-------------------------------------------+-------------------------------------------------------------+
    | Why introduced       | git checkout confusion                    | checkout mixed branch switching, file restore, discard       |
    |                      |                                           | git switch focuses on ONE job: switching branches            |
	+----------------------+-------------------------------------------+-------------------------------------------------------------+
	
	
	
	
    +----------------------+-------------------------------------------+-------------------------------------------------------------+
    | Basic syntax         | git switch <branch-name>                 | Switches to the specified branch                             |
    +----------------------+-------------------------------------------+-------------------------------------------------------------+
    | Switch branch        | git switch develop                       | Switches from current branch to develop                      |
    +----------------------+-------------------------------------------+-------------------------------------------------------------+
    | Create & switch      | git switch -c feature-login              | Creates new branch and switches to it                        |
    | (new feature)        |                                           | Replaces: git checkout -b feature-login                      |
    +----------------------+-------------------------------------------+-------------------------------------------------------------+
    | Create from main     | git switch -c feature-payment main        | Creates feature-payment branch from main and switches        |
    +----------------------+-------------------------------------------+-------------------------------------------------------------+
    | Force create switch  | git switch -C feature-login               | Recreates branch and switches to it                          |
    |                      |                                           | Resets branch to current HEAD (use carefully)                |
    +----------------------+-------------------------------------------+-------------------------------------------------------------+
    | Switch remote branch | git switch feature-login                  | Creates local branch if origin/feature-login exists          |
    |                      |                                           | Automatically sets upstream tracking                         |
    +----------------------+-------------------------------------------+-------------------------------------------------------------+
    | Switch previous      | git switch -                              | Toggles between last two branches                            |
    +----------------------+-------------------------------------------+-------------------------------------------------------------+
    | Clean tree check     | git switch main                           | Blocks switch if uncommitted changes conflict                |
    |                      |                                           | Options: commit, stash, or discard changes                   |
    +----------------------+-------------------------------------------+-------------------------------------------------------------+
    | Comparison           | git switch vs git checkout                | switch = branch only, checkout = branch + files              |
    |                      |                                           | git switch is recommended modern practice                   |
    +----------------------+-------------------------------------------+-------------------------------------------------------------+
    | When to use          | Branch switching                          | Daily development branch navigation                          |
    |                      | Branch creation                           | Cleaner, safer Git workflow                                  |
    +----------------------+-------------------------------------------+-------------------------------------------------------------+
    | When NOT to use      | Discard file changes                      | Use git restore instead                                      |
    |                      | Restore files                             | git switch cannot handle files                               |
    +----------------------+-------------------------------------------+-------------------------------------------------------------+
    | Alternative command  | git restore                               | Used for discarding or restoring file changes                |
    +----------------------+-------------------------------------------+-------------------------------------------------------------+
    | Cheat sheet          | git switch main                           | Switch to main branch                                        |
    |                      | git switch develop                       | Switch to develop branch                                     |
    |                      | git switch -c feature-login              | Create & switch to feature branch                            |
    |                      | git switch -c feature-payment main        | Create from main                                             |
    |                      | git switch -C feature-login              | Force recreate branch                                        |
    |                      | git switch -                              | Switch to previous branch                                    |
    +----------------------+-------------------------------------------+-------------------------------------------------------------+
    | Key takeaway         | git switch = branch-only command           | Cleaner, safer, recommended over git checkout for branching  |
    +----------------------+-------------------------------------------+-------------------------------------------------------------+

🟢## prune 

git prune physically deletes unreachable objects
Powerful but dangerous if misused
Prefer:

git fetch --prune (remote cleanup)
git gc (safe repository maintenance)

git prune vs git fetch --prune vs git gc (comparison table)


------------------------------------------------------------------
    +---------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Category                  | Command / Concept                             | Description / Uses / Examples                               |
    +---------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | What is git prune         | git prune                                     | Removes unreachable Git objects from local repository       |
    |                           |                                               | (old commits, blobs, trees not referenced anymore)          |
    +---------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Purpose                   | Repository cleanup                            | Frees disk space and cleans dangling objects                |
    +---------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Important note            | Internal / low-level command                  | Usually NOT run directly by users                           |
    +---------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Recommended alternative  | git gc                                        | Safer high-level command that runs prune internally          |
    +---------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Recommended alternative  | git fetch --prune                             | Cleans stale remote-tracking branches (safe & common)       |
    +---------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | What it removes           | Unreachable objects                           | Objects not referenced by any branch, tag, or reflog        |
    +---------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | What it does NOT remove   | Local branches                                | Does NOT delete local working branches                      |
    |                           |                                               | Does NOT delete reachable commits                           |
    +---------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Basic usage               | git prune                                     | Deletes unreachable objects immediately                     |
    +---------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Dry run                   | git prune -n                                  | Shows what would be removed (no deletion)                   |
    +---------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Verbose mode              | git prune -v                                  | Shows detailed output of pruned objects                     |
    +---------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Expire time               | git prune --expire <time>                     | Removes objects older than specified time                   |
    |                           | git prune --expire=now                        | Removes all unreachable objects immediately                 |
    +---------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Practical use case        | After deleting branches                       | Cleans objects left behind by removed branches              |
    +---------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Remote branch cleanup     | git fetch --prune                             | Removes stale remote-tracking branches (origin/xyz)         |
    +---------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Remote-only pruning       | git remote prune origin                       | Cleans local references of deleted remote branches          |
    +---------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Difference from fetch     | git fetch                                    | Downloads updates only                                      |
    |                           | git fetch --prune                             | Downloads + removes stale remote refs                       |
    +---------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Difference from gc        | git gc                                       | Runs prune + compresses repo (recommended)                  |
    |                           | git prune                                     | Only removes unreachable objects                            |
    +---------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Safety warning            | Manual execution                              | Can permanently delete objects                              |
    |                           |                                               | Use -n before running                                       |
    +---------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | When to use               | Repository maintenance                       | Disk cleanup, corruption issues, stale objects              |
    +---------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | When NOT to use           | Daily workflow                                | Prefer git gc or git fetch --prune                          |
    +---------------------------+-----------------------------------------------+-------------------------------------------------------------+
    | Key takeaway              | git prune                                     | Low-level cleanup tool; powerful but risky                  |
    |                           |                                               | Prefer safer alternatives for normal usage                 |
    +---------------------------+-----------------------------------------------+-------------------------------------------------------------+

🟢## git stash
git desktop stash => select all files and right click on changed file check box/label

Stash retrieve, show, list, delete & save

#stash

Command                                      | Description
---------------------------------------------|---------------------------------------------------------------
git stash                                    | Stash tracked modified files
git stash --keep-index                       | Stash only untracked files; keep staged files intact
git stash --include-untracked                | Stash tracked + untracked files
git stash list                               | Show all stash entries
git stash save "stash name"                  | Create a stash with a custom message
git stash show                               | Show files changed in the most recent stash
git stash show <stash id>                    | Show files changed in the specified stash (e.g., stash@{0})
git stash show -p                            | Show detailed diff/content of the latest stash content
git stash -- <file name>                     | Stash only the specified file
git stash -m "message" -- <file name>        | Stash a specific file with a message
git stash -m "my stash"                      | Create stash with a message

git stash pop                                | Apply latest stash and remove it from stash list
git stash apply <stash id>                   | Apply stash without removing it

git stash drop <stash id>                    | Delete specific stash entry delete stash
git stash clear                              | Remove all stash entries

git stash branch <branch> <stash id>         | Create new branch and apply stash to it



git stash list                               | List all stashes (duplicate reference from above)
git stash show stash@{n}					 | show list of stash files summary 	
git stash show -p stash@{n}                  | View diff/content of stash index n
git show stash@{n}:path/file                 | View full content of a specific file from stash 
git stash apply stash@{n}                    | Apply stash entry n without removing
git stash branch <name> stash@{n}            | Extract stash into new branch

git show stash@{0}:.env                                >> View full content of a specific file from stash

git checkout jthawkn_master_iso   => checkout branch in which you want to mearge
git merge origin/master_iso  => branch from which you want to mearge

🟢## Undo/revert/discard  changes
#  Undo | Reset hard & mixed, revert and restore 
#  Undo/revert/discard  code 

   rebase                  Reapply commits on top of another base tip
   reset                   Reset current HEAD to the specified state
   restore                 Restore working tree files
   revert                  Revert some existing commits
====================

# Git Undo 
git reset =>staging to local
git reset <commit id>  => remove from staging 
git reset --hard <commit id>   => remove from staging and local/ working

====================


# Git Undo  rvert code
git reset <-HASH ID->  =>staging to local
git reset <commit id>  => remove from staging 
git reset --hard <commit id>   => remove from staging and local/ working revert from every places
git reset HEAD <file name> 
git restore <filename>  // to discard changes in working directory
git restore --stage <filename>   // if file present in stage area and we want to restore. it will move in change area
git restore --stage --worktree . // (dot) every thing will discard from working tree  
git restore --stage  .


git revert <commitid>

☑️ impl : Associated Functions
----------
Key Characteristics of Associated Function

No self parameter:
	Unlike methods, associated functions do not take self, &self, or &mut self as their first parameter because they operate on the type, not on an instance of the type.


Namespaced by the Type:
	You call them using the type’s name followed by ::, such as
	TypeName::function_name().
Common Use Cases:
	• Constructors:
	Functions like new or custom builders that return new instances of the type.
	• Utility Functions:
	Functions that perform calculations or operations relevant to the type but don’t need an instance (e.g., String::from).

struct Rectangle { width: u32, height: u32 }

impl Rectangle {
    // Associated function (constructor)
    fn new(width: u32, height: u32) -> Self {
        Self { width, height }
    }

    // Another associated function (specialized constructor)
    fn square(size: u32) -> Self {
        Self { width: size, height: size }
    }

    // A method (note the &self)
    fn area(&self) -> u32 {
        self.width * self.height
    }
}

fn main() {
    let r = Rectangle::new(10, 20);
    let s = Rectangle::square(3);

    println!("r area = {}", r.area());
    println!("s area = {}", s.area());
}

☑️ impl : Method

Method Syntax

Methods are similar to functions: we declare them with the fn keyword and a name, they can have parameters
and a return value, and they contain some code that's run when the method is called from somewhere else.
Unlike functions, methods are defined within the context of a struct or an enum, and their first parameter is
always self, which represents the instance of the struct the method is being called on.
--------------
Defined within an impl block:

	Methods are defined in an impl block for a specific type (e.g., struct, enum).

First Parameter is self:

	Methods always take self, &self, or &mut self as the first parameter.
	This indicates that the method operates on the instance of the type:
	
	self: Takes ownership of the instance.
	&self: Borrows the instance immutably.
	&mut self: Borrows the instance mutably.

Called using Dot Notation:

	Methods are called using dot syntax:
	instance.method_name(),
	which makes them feel intuitive and object‑oriented.
-------------

🟦   Associated Function and Method 
struct Circle {
    radius: f64,
}

impl Circle {
    // Associated function (constructor)
    pub fn new(radius: f64) -> Circle {
        Circle { radius }
    }

    // Instance method
    pub fn area(&self) -> f64 {
        std::f64::consts::PI * self.radius * self.radius
    }
}

fn main() {
    // Call the associated function `new` to create a `Circle` instance
    let circle = Circle::new(5.0);

    // Call the instance method `area` on the `Circle` instance
    println!("The area of the circle is {}", circle.area());
}

        match *self {
            Shape::Circle(radius) => std::f64::consts::PI * radius * radius,

            Shape::Rectangle(width, height) => width * height,

            Shape::Triangle(a, b, c) => {
                let s = (a + b + c) / 2.0;   // Semiperimeter
                (s * (s - a) * (s - b) * (s - c)).sqrt()   // Heron's formula
            }
        }
    }
}

fn main() {
    let circle = Shape::Circle(3.0);
    let rectangle = Shape::Rectangle(2.0, 4.0);
    let triangle = Shape::Triangle(3.0, 4.0, 5.0);

    println!("Area of the circle: {}", circle.area());
    println!("Area of the rectangle: {}", rectangle.area());
    println!("Area of the triangle: {}", triangle.area());
}

Hashmap

In Rust, a HashMap is a key-value store, similar
to dictionaries in Python or maps in Java.

Key Features:

· Stores data as key-value pairs.

· Fast lookup using a hash function.

· Keys must be unique.

. Provided by Rust's standard library in

----------------------------------------------------------------------------------------
use std::collections::HashMap;

fn main() {
    // Create a HashMap<String, u32>
    let mut students: HashMap<String, u32> = HashMap::new();

    // Insert entries (String keys, u32 values)
    students.insert("Ravi".to_string(), 100);
    students.insert("Raju".to_string(), 10);
    students.insert("Lalu".to_string(), 1);

    // Iterate (borrowed) and print
    for (student, marks) in &students {
        println!("Student name: {:<5} marks: {}", student, marks);
    }

    // Update an existing key: insert returns the old value (if any)
    // This will update Raju from 10 -> 200
    if let Some(old) = students.insert("Raju".to_string(), 200) {
        println!("Updated 'Raju': old marks = {}, new marks = {}", old, students["Raju"]);
    }

    // Look up a key using get (returns Option<&u32>)
    match students.get("Raju") {
        Some(marks) => println!("Found: {}", marks),
        None => println!("Not Found"),
    }

    // Alternative: mutate in-place using get_mut
    if let Some(m) = students.get_mut("Lalu") {
        *m += 5;
        println!("After bonus, Lalu = {}", m);
    }

    // Show final map (order not guaranteed)
    println!("All students: {:?}", students);
}

☑️ Display Format
use std::fmt::Debug;
use std::fmt::Display;

{} 			#Display (pretty, user-friendly) 	#Display trait
{:?}		#Debug format						#Debug trait
{:#?} 		#Pretty Debug (multi-line)			#Debug trait
{:?} = Debug formatter

It tells Rust:

“Print this value using the Debug trait.”
✔ When to use {:?}
Use it when you want to print:
structs
enums
tuples
vectors/slices
anything with #[derive(Debug)]
--------------------------------------------
#[derive(Debug)]
struct User {
    name: String,
    age: u8,
}

fn main() {
    let u = User {
        name: "Alice".into(),
        age: 30,
    };

    println!("{:?}", u);
}
``

It prints the memory address, not the value stored inside.
{:p} formats its argument as a pointer
a reference &T
a raw pointer *const T or *mut T
anything that implements Pointer


fn main() {
    let x = 10;
    println!("Address of x: {:p}", &x);
}

println!("{:p}", &10);
``
Sample output: Address of x: 0x7ffee7d63a3c

fn main() {
    let x = 10;
    let bx = Box::new(20);

    println!("Stack variable x:  {:p}", &x);
    println!("Box pointer (stack): {:p}", &bx);
    println!("Box inner value (heap): {:p}", bx.as_ref());
}

☑️ clear and practical explanation of the difference between : and :: in Rust.

Symbol | Meaning
-------|------------------------------------------------------------
::     | Path separator: access modules, types, traits, enum variants
:      | Type annotation, trait bounds, function signatures, fields
----------

:: is used to access items inside modules, types, enums, and traits.
std::fs::File
String::from("hello")
Vec::new()
Option::Some(10)
Result::Ok("done")
std::f64::consts::PI
ToString::to_string(&123)

-------------------------------------------------------
Type annotations
Rustlet x: i32 = 10;

Function parameter / return type annotations
fn add(a: i32, b: i32) -> i32 { a + b }

Struct fields

struct Person {
    name: String,
    age: u32,
}

Trait bounds (generics)

fn print<T: std::fmt::Debug>(x: T) {
    println!("{:?}", x);
}
